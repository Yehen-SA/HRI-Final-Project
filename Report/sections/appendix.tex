\subsubsection{Teammate Perception}

\begin{enumerate}[leftmargin=*, itemsep=0.8em]

    \item I felt that the robot was part of my team.

    \item I felt that the robot and I were working towards a common goal.

    \item I felt that the robot was just a tool.

\end{enumerate}

\subsubsection{Robot Evaluation}

\begin{enumerate}[leftmargin=*, itemsep=0.8em, start=4]

    \item I considered the robot capable of performing its role in the game.

    \item I would trust this robot to contribute to a team task.

\end{enumerate}

\subsubsection{Teamwork Experience}

\textit{Please answer only the questions corresponding to your experimental condition.}

\paragraph{Shared-score condition}

\begin{enumerate}[leftmargin=*, itemsep=0.8em, start=6]

    \item I felt that the robot made a valuable contribution to our team's performance.

    \item I felt that the workload was fairly shared between the robot and me.

    \item I was motivated to improve our team's overall score.

\end{enumerate}

\paragraph{Separate-score condition}

\begin{enumerate}[leftmargin=*, itemsep=0.8em, start=6]

    \item I paid more attention to my own score than to the robot's score.

    \item I felt that I was competing with the robot.

    \item Having separate scores made me more motivated to improve my own performance.

\end{enumerate}

\subsubsection{Overall Teamwork Experience}

\begin{enumerate}[leftmargin=*, itemsep=0.8em, start=9]

    \item I was willing to help the robot when it was struggling during the game.

\end{enumerate}

\section{Data collection}
\label{app:data}
Two rows per participant, one per robot round. Conditions follow the participant ID (see the game's \texttt{assignment.py}). Tick \textit{Started} when an ID is handed out, so it isn't used twice. Values come from each participant's log file (\texttt{uv run tools/summarise\_logs.py} prints them). Every other measure, including steals and rescues, is kept in \texttt{Data/results.csv} in the project repository.
\begin{itemize}[nosep]
    \item \textit{Possession}: seconds the human's and the robot's balls were in flight.
    \item \textit{Score}: points scored by the human, the robot and the team.
\end{itemize}
