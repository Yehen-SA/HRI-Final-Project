# HRI Breakout: Windows version

This folder holds the packaged Windows game, `HRI_Breakout.exe`, built by
`../build_exe.ps1` (run it on Windows; see the top of that script). The .exe isn't kept in
git, so build it before sending.

## What to send a participant

`HRI_Breakout.exe` and their participant ID (e.g. P07). The instructions below can go in the
email.

---

## Instructions for participants

1. Save `HRI_Breakout.exe` somewhere you can find it, such as your Desktop or Downloads.
2. Double-click it. Windows may warn that the app is from an unknown publisher: click
   **More info**, then **Run anyway**. (It isn't signed because it's a student project.)
3. Type the participant ID you were given, then follow the instructions on screen. It takes
   about 15 minutes. Use a keyboard; sound on is best.
4. At the end, the game shows where it saved your results file: a `logs` folder next to
   `HRI_Breakout.exe`, with a file named like `2026-11-20_143000_P07.md`.
   **Please email that file back to us.**

To stop early, press Esc twice. Your results so far are still saved in the `logs` folder.
